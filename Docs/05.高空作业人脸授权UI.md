# 高空作业吊篮人脸授权 UI

## 目标

操作人员通过右侧摄像头完成身份核验，左侧界面明确展示验证进度和上机权限。界面首先服务于现场安全判断：当前是否能验证、验证是否通过、是否允许上机，不能依赖颜色或动画猜测。

## 布局

屏幕为 1024×600：

| 区域 | 范围 | 内容 |
|------|------|------|
| 左侧授权界面 | x 0~416，y 0~600 | LVGL 图层 0 |
| 右侧摄像头 | x 432~1008，y 12~588 | OV2640 576×576 RGB565，LTDC 图层 2 |

左侧界面自上而下分为四层：

1. 黄色安全横条：设备名称、终端用途、设备编号和在线状态。
2. 核验结论：当前状态和操作引导。
3. 圆形进度与结果面板：采集状态、身份比对、上机权限。
4. 三步流程和唯一主按钮：人脸采集 → 身份比对 → 作业授权。

## 视觉系统

| Token | 色值 | 用途 |
|-------|------|------|
| 石墨底 | `#0B0E11` | 页面底色 |
| 钢板面 | `#171C22` | 结果面板 |
| 次级面 | `#20262E` | 分隔线与未激活步骤 |
| 安全黄 | `#F2C94C` | 待验证、采集中、危险区警示 |
| 通行绿 | `#18C29C` | 验证通过、允许上机 |
| 拒绝红 | `#E34D59` | 验证失败、禁止上机 |
| 正文 | `#E5E9EF` | 主要文字 |
| 弱化文字 | `#87929F` | 说明和未激活状态 |

字体使用黑体子集：14px 用于正文与数据，24px 用于状态结论与主动作。所有主要内容左对齐；结果面板只使用一块硬边容器，安全黄横条是界面唯一强视觉元素。

## 状态机

| 状态 | 标题 | 主按钮 | 上机权限 |
|------|------|--------|----------|
| 待验证 | 等待身份核验 | 开始人脸验证 | 未授权 |
| 采集中 | 正在核验 | 验证中，请保持面部稳定 | 未授权 |
| 验证通过 | 验证通过，允许上机 | 重新验证 | 允许上机 |
| 验证失败 | 验证未通过 | 重新验证 | 禁止上机 |

## 算法接入

当前 `FACE_UI_DEMO_FLOW=1`，用于在没有人脸算法时走通所有界面状态。接入真实识别服务时：

1. 将 `FACE_UI_DEMO_FLOW` 设为 `0`。
2. 用真实采集进度更新 `lv_arc_set_value()`。
3. 用真实识别结果调用 `apply_face_state(FACE_UI_VERIFIED)` 或 `apply_face_state(FACE_UI_REJECTED)`。
4. 将“上机权限”状态连接到现场联锁输出，界面不能单独作为安全授权依据。
