# 竖屏人脸授权 UI

## 当前状态

物理面板为 1024×600，实际安装方向为竖屏。LVGL 保持原生 1024×600 显示，再通过实机确认的 270° 旋转得到 600×1024 逻辑画布。

当前已完成 UI 设计层：

- 512×512 预览/冻结照片区域；
- 等待页顶部 600×600 无缝彩条滚动占位，可替换为动态广告内容；
- 环形验证进度；
- “开始上机 → 开始拍照 → 开始验证”三步位置提示；
- 单一主按钮和六个演示状态。

相机已接入按需预览，不做软件旋转：待机不采集，点击“开始上机”启动 512×512 预览，点击“开始拍照”停止 DCMI/DMA 并冻结最后完整帧。真实身份识别算法仍未接入。

## 状态机

| 状态 | 状态标题 | 主按钮 | 行为 |
|------|----------|--------|------|
| IDLE | 等待上机验证 | 开始上机 | 进入预览步骤 |
| PREVIEW | 请正视摄像头 | 开始拍照 | 冻结当前完整帧 |
| PHOTO_READY | 确认抓拍 | 开始验证 / 重拍 | 确认抓拍后验证，或重新启动预览拍照 |
| SCANNING | 身份比对 / 上机授权 | 验证中 | 按钮禁用，环值递增 |
| VERIFIED | 授权通过 | 重新验证 | 返回待机 |
| REJECTED | 验证未通过 | 重新验证 | 返回待机 |

步骤行只高亮当前步骤：已过步骤为绿色，当前步骤为黄色或红色，未到达步骤为弱化色。主按钮始终只有一个当前动作。

确认抓拍时，底部“重拍”和“开始验证”为两个等宽、同字号按钮。

## 显示与触摸

- 显示：`lv_display_set_rotation(disp, LV_DISPLAY_ROTATION_270)`。
- flush：`lv_display_rotate_area()` 得到物理区域，`lv_draw_rotate()` 写入原生 SDRAM。
- 触摸：驱动上报原始 1024×600 坐标，由 LVGL v9 输入层根据显示旋转自动转换到 600×1024 逻辑坐标；回调内不能再次旋转。
